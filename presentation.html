📊 Dashboard 1: Price Trends

Best Time to Book

💰 Problem: Price Optimization

“When should I book to pay less?”

Customers don’t know:

  • How prices change over time
  • When is the optimal booking window
  • If they should wait or book now

Solution: Analyze price vs days_left to find patterns

📈 Price vs Days Before Departure

Code 
# Calculate average price by days left
price_by_days <- data %>%
  group_by(days_left) %>%
  summarise(
    avg_price = mean(price),
    min_price = min(price),
    max_price = max(price),
    .groups = "drop"
  )

# Create the plot
p1 <- ggplot(price_by_days, aes(x = days_left, y = avg_price)) +
  geom_ribbon(aes(ymin = min_price, ymax = max_price), 
              fill = colors$secondary, alpha = 0.2) +
  geom_line(color = colors$primary, linewidth = 1.5) +
  geom_point(color = colors$primary, size = 2) +
  scale_x_reverse() +
  scale_y_continuous(labels = label_comma(prefix = "₹")) +
  labs(
    title = "Flight Prices by Booking Window",
    subtitle = "Average price with min/max range",
    x = "Days Before Departure",
    y = "Price (₹)"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold", size = 16, color = colors$primary),
    plot.subtitle = element_text(color = "gray50")
  )

print(p1)

💡 Key Insight: Price Trends

Booking Recommendation

Book 15-30 days before departure for optimal prices.

  • Last-minute bookings (< 3 days) are 30-50% more expensive
  • Prices stabilize around 2-3 weeks before departure
  • Very early bookings (> 45 days) don’t guarantee savings

📊 Dashboard 3: Stops Analysis

Direct vs Connecting Flights

🔄 Problem: Stops Trade-off

“Is it better to take a direct flight or with stops?”

The dilemma:

  • Direct flights are faster but more expensive
  • Connecting flights save money but take longer
  • Is the time saved worth the extra cost?

Solution: Compare stops vs price vs duration

📊 Price & Duration by Stops

Code 
# Calculate stats by stops
stops_stats <- data %>%
  group_by(stops) %>%
  summarise(
    avg_price = mean(price),
    avg_duration = mean(duration),
    count = n(),
    .groups = "drop"
  ) %>%
  mutate(stops_label = case_when(
    stops == "zero" ~ "Direct",
    stops == "one" ~ "1 Stop",
    TRUE ~ "2+ Stops"
  ))

# Create side-by-side plots
library(patchwork)

p4a <- ggplot(stops_stats, aes(x = stops_label, y = avg_price, fill = stops_label)) +
  geom_col(show.legend = FALSE) +
  geom_text(aes(label = paste0("₹", format(round(avg_price), big.mark = ","))), 
            vjust = -0.5, size = 5, fontface = "bold") +
  scale_fill_manual(values = c(colors$success, colors$warning, colors$accent)) +
  scale_y_continuous(labels = label_comma(prefix = "₹"), expand = c(0, 0, 0.15, 0)) +
  labs(title = "Average Price", x = "", y = "Price (₹)") +
  theme_minimal() +
  theme(plot.title = element_text(face = "bold", size = 14, hjust = 0.5))

p4b <- ggplot(stops_stats, aes(x = stops_label, y = avg_duration, fill = stops_label)) +
  geom_col(show.legend = FALSE) +
  geom_text(aes(label = paste0(round(avg_duration, 1), "h")), 
            vjust = -0.5, size = 5, fontface = "bold") +
  scale_fill_manual(values = c(colors$success, colors$warning, colors$accent)) +
  scale_y_continuous(expand = c(0, 0, 0.15, 0)) +
  labs(title = "Average Duration", x = "", y = "Duration (hours)") +
  theme_minimal() +
  theme(plot.title = element_text(face = "bold", size = 14, hjust = 0.5))

p4a + p4b + plot_annotation(
  title = "Direct vs Connecting Flights Comparison",
  theme = theme(plot.title = element_text(face = "bold", size = 16, color = colors$primary))
)

time_stats <- data %>%

City-to-City Optimization

“What’s the best option for my specific route?”

Each route has different:

  • Price ranges
  • Available airlines
  • Flight durations

Solution: Filter by source_city → destination_city

📊 Top Routes by Volume

Code 
# Calculate route statistics
route_stats <- data %>%
  group_by(source_city, destination_city) %>%
  summarise(
    count = n(),
    avg_price = mean(price),
    min_price = min(price),
    .groups = "drop"
  ) %>%
  mutate(route = paste(source_city, "→", destination_city)) %>%
  arrange(desc(count)) %>%
  head(10)

p6 <- ggplot(route_stats, aes(x = reorder(route, count), y = count, fill = avg_price)) +
  geom_col() +
  geom_text(aes(label = paste0("Avg: ₹", format(round(avg_price), big.mark = ","))), 
            hjust = -0.1, size = 3.5) +
  scale_fill_gradient(low = colors$success, high = colors$accent, 
                      labels = label_comma(prefix = "₹")) +
  coord_flip() +
  scale_y_continuous(expand = c(0, 0, 0.25, 0)) +
  labs(
    title = "Top 10 Flight Routes",
    subtitle = "By number of available flights",
    x = "",
    y = "Number of Flights",
    fill = "Avg Price"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold", size = 16, color = colors$primary)
  )

print(p6)

📊 Dashboard 6: Value Score

Smart Flight Recommendations

⭐ Problem: Best Overall Value

“Which flight is the BEST choice, not just the cheapest?”

The best flight balances:

  • 💰 Price (affordable)
  • ⏱️ Duration (fast)
  • 🔄 Stops (convenient)

Solution: Calculate a Value Score

📊 Value Score Formula

# Value Score Calculation - Lower score = Better value

# Normalize each factor (0-1 scale)
# Score = (Price weight × Price_norm) + 
#         (Duration weight × Duration_norm) + (Stops penalty)

# Example weights: Price: 50%, Duration: 30%, Stops: 20%

\[ \text{Value Score} = 0.5 \times \frac{P - P_{min}}{P_{max} - P_{min}} + 0.3 \times \frac{D - D_{min}}{D_{max} - D_{min}} + 0.2 \times S_{penalty} \]

Where \(S_{penalty}\) = 0 (direct), 0.3 (1 stop), 0.6 (2+ stops)

Smart Recommendation

The Value Score helps identify flights that are:
